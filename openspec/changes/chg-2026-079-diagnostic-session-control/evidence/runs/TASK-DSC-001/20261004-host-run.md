# Bounded Diagnostic Session — macOS host verification

Date: 2026-10-04. Task: TASK-DSC-001. Change: CHG-2026-079-diagnostic-session-control@r1.
This is implementation and host/fixture evidence, not a device acceptance or change approval.

The App submits one exact-target `capture.diagnostic-session@1` Job, waits for Runtime readiness,
records bounded host annotations, and shortens the admitted recording wait on Stop. The Runtime
uses a monotonic deadline and accepts no caller timestamp, device command, target override or
capability. Loss of the owner, control publication or an effect receipt preserves uncertainty and
stops new device dispatch. Stop/deadline freezes annotations before trace finalization.

`diagnostics session status|mark|stop` uses the same closed controls. CLI and App offline readers
consume the new operation's actual fake-Runtime products with metadata/digest binding; they do not
invent a missing UI dump or cross-clock alignment. Trace opening pins the source operation.
The shared producer fixture is `rust/tests/fixtures/diagnostic-session/interactive.json`.
