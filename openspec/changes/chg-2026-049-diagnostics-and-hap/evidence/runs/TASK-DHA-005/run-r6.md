## 一处对已批准提案的偏离(需 reviewer 知情)

r6 写的 `crashLogName` pattern 是 `^[a-z]+crash-…`。**该 pattern 会拒绝
`appfreeze-…`** —— Faultlogger 装的不只是 crash(还有 appfreeze / sysfreeze),
而我只实测过 `jscrash`。实现改为只约束**形状**:
`^[a-z]+-[A-Za-z0-9._-]{1,180}$` —— 小写前缀 + 有界字符 + **无分隔符**。

理由:枚举没在设备上见过的类型词表,正是这张事实表反复在纠正的错误。
pattern 的职责是"不能是路径/shell 片段",不是"猜类型"。设备没有的名字自己会回
`invalid parameters.`,由 verify 判 `.failed`。
