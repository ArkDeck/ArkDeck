# TASK-XPA-011 — Windows analyzer provider (WM3 GJ-5, PR 1), 2026-09-30 / 2026-10-04

- Task: TASK-XPA-011, WM3 slice GJ-5, first PR: the analyzer provider on Windows. The host
  composes it, the planner materializes against it, the runner executes it, and the daemon
  serves its two analyzer child modes, all for `analyzer.extract-crash-signature@1` and
  `analyzer.summarize-hilog@1`. The two ArkTrace analyses stay unavailable (TASK-XPA-021).
  Later GJ-5 PRs cover the workspace provider, the `workspace.*` operations, the keystore
  password in Credential Manager, the registered toolchains, the HAR console challenge and
  the `workspace.sign-openharmony-hap@1` dispatch (see "Left out").
- Base: one commit on `origin/main` `3efba88c` (#2444). Started on `2c1480ba` (#2401) and
  rebased after the host shutdown of 2026-10-01: the Windows `planning` field and runner now
  carry the composed analyzers beside the Import owner and the Flash lane that landed since.
- Host: the Windows 11 x64 reference host (Windows 11 Pro 10.0.26200), non-elevated. Nothing
  was installed, elevated or reconfigured. No board, `hdc`, DevEco, JDK, keystore or
  credential was used. Every daemon ran over a private development root with every other
  `ARKDECK_`/`OHOS_HDC_` input removed.

## Delegated minor decisions, pending the next rulings batch

1. **The analyzer child's source argument is the canonical path.** Windows has no `/.vol`
   alias, so the analyzer child is given the held source's canonical path. This is the same
   substitution #2354 made for the signing tools. The oracle cases that name `{inputVolume}`
   are replayed with that path.
2. **A Windows analyzer executable is a PE image the caller may execute.** This replaces
   "a regular file with an execute bit". It is measured through one handle that follows no
   reparse point.
3. **ArkTrace on Windows.** The two ArkTrace analyses are unavailable as
   `analyzer.arktraceNotFound` (`AnalyzerProfiles::without_arktrace`), and
   `ARKDECK_ARKTRACE_DESCRIPTOR` refuses the start rather than being ignored. This holds
   until TASK-XPA-021 reviews a Windows ArkTrace distribution.

## Left out, and why

- **The ArkTrace analyses** stay unavailable: no ArkTrace distribution or `trace_streamer` is
  reviewed for Windows (TASK-XPA-021).
- **The oracle cases that need a POSIX file system** (`/.vol` aliases, links, FIFOs, modes,
  a trailing solidus) are the macOS replay's.
- **Re-entry of a finished run with the same `--execution-id`.** The Runtime answers
  `job.run` of a terminal Job with `resourceConflict` on both hosts, so the executor reports
  `transportFailure` for it. The restart leg therefore measures a new execution rather than
  that re-entry.
- **The remaining GJ-5 scope**: the workspace provider and `WorkspaceComposition`, the
  `workspace.*` operations, the keystore password in Credential Manager (#2354), toolchains
  only from registered references (G2's hvigor/node registration), the HAR console
  challenge, and `workspace.sign-openharmony-hap@1` over #2372's attempt root with a fake
  java/hvigor. These are later PRs of this slice.
- **Anything device-bound.** The Windows HDC tuple is not registered, so no device, `hdc`
  or DAYU200 was touched.
