## Delegated minor decisions, pending the next rulings batch

1. **`debug template run` stays `partial`.**
   - The CLI leaf runs the `debug.template@1` Job. The `debug.template.run` control method,
     which the Control replay above holds to Swift's answers, is the App's deprecated direct
     path.
   - The Job's admission observes the Target through `list targets` and the identity reads.
   - No Swift oracle records those answers for this Job, so the fake has none to give. A probe
     through the CLI was refused with `outcomeUnknown` ("empty observation output").
2. **The fake's killed template.**
   - The fake reports it as the runner's report of a child that died on signal 9
     (`signal_death(9)`, an unobservable outcome), which is the recorded answer.
   - The Windows runner sees no signals, so the replay holds the read's classification of that
     outcome, not a Windows runner's wording.
