# Remaining Windows work

Updated 2026-09-30 against protected main `66b7474b` (#2326), revision 12 as proposed. The Windows
phase opens when r12 merges; phase S is the software, phase A the maintainer's real-host and
DAYU200 acceptance (proposal r12). This table is refreshed once per milestone in its own docs PR,
not in every slice.

| Operations executable on Windows (/30) | Methods the Windows daemon answers (/105) | GJ software-ready on Windows (/5) | GJ real device on Windows (/5, phase A) | CLI coverage `windows: implemented` (/256) | Client pages (/6 + 1 skeleton) | SPK-3 / SPK-4 / SPK-5 |
| --- | --- | --- | --- | --- | --- | --- |
| 0 | 3 by design (`doctor`, `operation.list`, `device.observations`); not re-measured, because no client reaches an unsigned daemon (XPA-AC-6) | 0 | 0 | 0 (140 `notImplemented`, 116 unset) | 0 + 0 | not run / not run / not run |

How each number is read:

- **Operations executable**: a Catalog operation that the Rust CLI runs end to end on Windows
  through the named pipe against the Rust daemon, with a fake HDC or stand-in lane on the device
  side. Plan-only or fixture replay does not count.
- **Methods answered**: control methods that reach an owner the Windows daemon composes. The
  three are the XPA-002 read-only foundation (`openspec/platforms/windows/profile.md`); every other
  method is compiled but reaches no owner, because the owners are composed under
  `cfg(target_os = "macos")`. The count is measured by a client once the development daemon
  identity of proposal r12 §8 exists.
- **GJ software-ready**: every runbook step of that Golden Journey passes on Windows with the fake
  HDC (exit condition 2 of `docs/design/cross-platform/windows-phase-agent-prompt.md`).
- **GJ real device**: `REAL_DEVICE_PASS` on the current Catalog digest, phase A only.
- **CLI coverage**: `implementationStatusByPlatform.windows == "implemented"` in
  `openspec/contracts/cli-feature-coverage.json`, generated by `rust/crates/arkdeck-cli/src/feature_coverage.rs`.
- **Client pages**: the XPA-007 skeleton and the six XPA-020 surfaces, each wired to the real
  Windows daemon.
- **Spikes**: pass / fail / not run, with the run record under `runs/<task>/spk-N-<date>-run.md`.
