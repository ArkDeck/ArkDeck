## Unicode validation and macOS CI follow-up

Foundation `CharacterSet.controlCharacters` contains both Cc and Cf scalars. That
made the App reject U+200C/U+200D/U+2060, including ordinary joined text and emoji,
although the private payload schema and Rust `char::is_control` exclude only
C0/C1 controls. The client now checks the scalar's `.control` general category.
A transport-level regression uploads emoji, Persian joiners and word joiners as
unchanged private payloads; Job inputs remain limited to the lease and epoch.
NUL, DEL and C1 inputs join the existing zero-call rejection cases.
