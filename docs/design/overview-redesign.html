ArkDeck Overview 重设计候选稿（记录优先）

设计输入，非 normative。规格正本是 docs/design/macos-ux-interaction-spec.md §5.1 与 openspec/specs/desktop-ux-observability/spec.md；两者与本稿不一致时以规格为准，行为级缺口走 behavior delta。 说明与取舍见 docs/design/overview-redesign.md。

页面数据全部是演示数据（沿用 prototype.html 的 DAYU200 / S-07xx 那套），不连接设备， 不代表任何真机事实，也不表示相关 operation 已 production available。颜色与间距取自 docs/design/arkdeck-ds/src/tokens.css，窗口几何取自 prototype.html。 随系统外观切换浅色 / 深色。
