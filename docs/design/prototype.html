ArkDeck macOS 交互原型 v1.3 — 与 docs/design/macos-ux-interaction-spec.md（draft v1.3）同版本。Viewer / Trace 已回写当前 SwiftUI 表面：Viewer 默认先显示真实空态，Trace 只保留抓取与查看入口。本轮按设计评审修订：Diagnostics 的 Marker 改为「标记 + 环形缓冲回溯取证」，截图按实际拍摄时刻标注（+N ms），新增自动 Marker；默认演示 Session 即第一版默认形态（无录屏），另有含录屏与 Partial/无法对齐两个 Session；选中 Trace event 的 identity 不再被日志/画面点击清空。Toolkit 新增长按、两态触点反馈（pending → confirmed）、tap 锚定按下点；预览常显画面年龄且断流时输入自动暂停；第一版录屏为宿主逐帧合成（无设备端拉取与残留）。所有数据均为演示数据，不连接设备；环形缓冲、自动 Marker、5 fps 预览、设备侧编码录屏均不代表相关 device operation 已 production available。
